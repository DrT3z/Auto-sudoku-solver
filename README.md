# Auto-sudoku-solver

## Solves a sudoku using a backtracking algorithm. 
The _grid_ array is the 9 by 9 sudoku grid and 0 is the empty cells.

The sudoku_screenshotter screenshots the sudoku grid (built for sudoku.com). You need to zoom in 150% for it to work. Press 'insert' on your keyboard to start.
It uses pyautogui to take screenshots of each cell and uses easyOCR to find the digit in the cell.
